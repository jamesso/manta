# Lessons

- Tailwind Preflight is vendored in `ui/styles/preflight-scoped.css` inside `@scope (:root) to (.print-area, .paper)`, so the invoice paper and PDF keep browser defaults. Keep it in its own `preflight` layer before `base`: scoped rules beat later unscoped rules of equal specificity (scope proximity), so in the same layer they override `base` rules.
- Any change to global CSS must pass `node scripts/pdf-snapshot.mjs <dir>` + `sh scripts/pdf-compare.sh <before> <after>` (expect ALL IDENTICAL). Build the "before" from `git archive HEAD` in /tmp with a symlinked node_modules.
- Window chrome color (`--sidebar`) must equal `WINDOW_BACKGROUND` in `main/theme.js`; e2e checks it.
- List pages use `ListPage` + `PageHeader` (`app/components/layout/PageHeader.jsx`) and the shared `FilterBar` / `FacetFilter` / `NoResults` (`app/components/filters/`); do not add per-page header markup or rows of status tabs. Other screens open a list page with `UIActions.openList(page, { status, query, openId })`.
- The "Previewer" BrowserWindow is hidden and is only the PDF render engine (`runPreviewPdfJob` in `main/preview-pdf-coordinator.js`). All preview UI lives in the main-window drawer (`app/components/preview/`). PDF/email/share/e-invoice IPC accepts only the main window main frame.
- Base UI `Select` shows the raw value in the trigger unless it gets an `items` list ({ value, label }) or `SelectValue` children. Give every `Select` an `items` list and render its `SelectItem`s from the same list. `ToggleGroup` takes and returns arrays (no Radix `type="single"`).
- Settings pages use `app/components/settings/SettingsLayout.jsx` (page header, group cards, rows); do not hand-roll headings or borders.
- For dark-mode screenshots in Playwright Electron, launch with `colorScheme: null`, or the page stays light.
- List tables use `app/components/table/DataTable.jsx` (`DataTable`, `SortHeader`, `selectColumn`, `useRowSelection`, `usePagination`, `SelectionBar`; render `SelectionBar` after the table) with `features` from `app/components/table/features.js`; set `meta: { align: 'end' }` for numeric columns. TanStack Table v9 reads `sortFn` on a column, not the v8 name `sortingFn` (v9 ignores it silently). Pass `autoResetPageIndex: false` with `usePagination`: v9 otherwise goes back to page 1 on every row refresh (`useNow` ticks each minute).
- Toasts sit bottom-left at `z-[60]`, above sheets and dialogs (`z-50`): drawers open on the right and the selection bar is bottom-center.
- Keep every drawer (`Sheet`) mounted and drive it with `open`; render an empty `SheetContent` when there is no record. Base UI does not animate a dialog that mounts already open. Read the record through `useSheetValue(open, value)` (`ui/components/ui/sheet.jsx`) so the content stays while the drawer slides out.
- `useDebouncedSave(value, …)` resets the draft when `value` changes identity. Pass a stable value (`useMemo` any derived object), or the settings page re-renders without end and open popups crash with React #185.
- Dropdown popups must line up with their box: `Select` opens below with `alignItemWithTrigger={false}` and `min-w-(--anchor-width)`; `ComboboxInput` renders its `InputGroup` through `Combobox.InputGroup` so the popup anchors to the whole box. Do not add `+--spacing(7)` widths.
- `npm run dev` runs `electron-vite dev --watch`: main-process changes rebuild and restart Electron, preload changes reload the window. Without `--watch` the main process keeps old code while the renderer hot-reloads, which causes errors like "No handler registered for '<channel>'".
- The UI supports RTL (`ur-PK` sets `<html dir="rtl">`). Use logical utilities (`start-*`/`end-*`, `ms-`/`me-`, `ps-`/`pe-`, `border-s`/`border-e`), not `left-*`/`right-*`, mainly on `fixed`/`absolute` elements: they do not follow the flex order. Exceptions: Base UI `data-side` (physical) and the macOS traffic-light padding.
